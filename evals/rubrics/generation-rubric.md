# 생성 결과 채점 기준 (generation rubric)

> 사람 평가자와 LLM Judge가 **같은 기준**으로 채점하기 위한 문서다. Judge 프롬프트
> (`evals/model_selection/judge_prompts.py`)는 이 문서의 판정 문항을 그대로 옮긴다 — 한쪽을 바꾸면 다른 쪽도 바꾼다.
>
> 원칙: **규칙으로 판정할 수 있는 것은 규칙으로 먼저 판정한다**(아래 1절). 사람·Judge는 2~4절만 본다.
> 1~5점 척도보다 **예/아니오/판단 불가** 판정을 우선한다(척도 점수의 쏠림·편향 이력, EVAL.md 26절).

## 1. 규칙 기반 판정 (사람·Judge 채점 대상 아님)

| ID | 항목 | 판정 | 코드 |
|---|---|---|---|
| R1 | 목표 개수 달성 | `len(items) == num_items` | `graders.py` |
| R2 | 형식 게이트 | 예시 형식 규칙(선지 수·`<보기>` 필수·합답형 선지·기호 일치) 위반 없음 | `app/modules/exam/tools._format_errors` 재사용 |
| R3 | 한국어 | 한자 비율 5% 미만 | `_check_korean` 재사용 |
| R4 | 예시 복사 | bigram containment < 0.90 | `_check_similarity` 재사용 |
| R5 | PII 노출 | 출력에 `mask_pii()`가 찾는 PII 없음 | `app/common/privacy.mask_pii` |
| R6 | 수정 JSON | 수정 응답이 스키마대로 파싱됨 | `graders.py` |
| R7 | 수정 범위 | 요청하지 않은 문항 번호가 바뀌지 않음 | `graders.py` |
| R8 | 문항 수 추출 | 입력에 명시된 개수와 exact match(명시 없으면 2) | `graders.py` |
| R9 | 형식 판정 | 요청 분석의 형식(`num_options`·`has_stimulus`·`combo`·`has_essay`)이 정답 형식과 모두 일치(형식이 섞인 긴 입력은 제외) | `graders.py` |
| R10 | 미지원 형식 안내 | 미지원 형식이면 안내가 있고, 지원 형식이면 없음 | `graders.py` |
| R11 | 채팅 의도 | 수정·질문·새로 만들기·인사 판정이 요청 종류와 일치. 질문·인사·범위 밖 요청에는 문항이 바뀌지 않음(R7) | `graders.py` |
| (라벨) | 정답 형식 | `evals/data/*.jsonl`의 `expected.format`은 게이트 규칙이 아니라 형식 키·사람이 정한 값 — 규칙이 틀려도 라벨은 틀리지 않는다 | `build_datasets.py` |

## 2. 문항 판정 (문항 1개 단위)

각 질문에 **예 / 아니오 / 판단 불가** 중 하나로 답하고, "아니오"나 "판단 불가"면 한 줄 근거를 쓴다.

| ID | 질문 | 치명적 오류 |
|---|---|---|
| I1 | **정답 키가 맞는가?** 표시된 정답 선지가 실제로 옳은 답인가(서술형은 예시 답안이 발문의 요구를 충족하는가) | 아니오 → X1 |
| I2 | **정답이 하나뿐인가?** 다른 선지도 정답으로 볼 수 있으면 아니오 | 아니오 → X2 |
| I3 | **사실 오류가 없는가?** 발문·제시문·선지·정답에 고교 교육과정 개념과 어긋나는 서술이 없는가 | 아니오 → X3 |
| I4 | **발문과 선지가 맞물리는가?** 예: 합답형 선지인데 발문이 "옳지 않은 것은?"이면 아니오. 부정형 발문인데 틀린 선지가 둘 이상이면 I2도 아니오 | 아니오 → 결함(비치명) |
| I5 | **예시 형식을 따르는가?** 예시가 `<보기>`형이면 `<보기>`가 실제 판단 재료로 쓰이는가(장식이 아닌가) | 아니오 → 결함(비치명) |
| I6 | **새 문항인가?** 예시를 표현만 바꿔 같은 것을 묻지 않는가 | 아니오 → X6 |
| I7 | 오답 선지가 같은 개념 범주에서 그럴듯한가 (진단용) | — |

### 판정 예시

- **I1·I2 아니오(복수 정답)**: "공공재의 특성으로 옳은 것은? ① 비배제성 ② 배타성이 없음 ③ 희소성이 있음 ④ 가격이 매우 낮음" → ①과 ②가 같은 뜻. I2 아니오.
- **I4 아니오**: 발문 "시장 실패의 사례로 옳지 않은 것은?" + 선지 "① ㄱ, ㄴ ② ㄱ, ㄷ …" → 합답형 선지와 단일 선택 발문이 맞지 않음.
- **I5 아니오**: `<보기>`에 ㄱ~ㄹ이 있지만 선지가 서술문이라 `<보기>`를 읽지 않아도 풀 수 있음.

## 3. 해설 판정 (문항 1개의 해설 단위)

| ID | 질문 | 치명적 오류 |
|---|---|---|
| E1 | 해설이 **표시된 정답과 같은 답**을 정답이라고 하는가 | 아니오 → X4 |
| E2 | 해설에 **사실 오류**가 없는가(예: 비배제성과 비경합성 혼동) | 아니오 → X3 |
| E3 | 오답 선지(또는 `<보기>` 진술)마다 틀린 이유를 설명하는가 | — (완전성) |
| E4 | 핵심 없이 길기만 하지 않은가(같은 말 반복, 문항과 무관한 서술) | — (간결성) |

> 정답 키가 틀린 문항(I1 아니오)의 해설은 E1이 "예"여도 **오류를 정당화한 해설**이다. 집계 시 I1과 함께 본다.

## 4. 수정 판정 (수정 요청 1건 단위)

| ID | 질문 |
|---|---|
| V1 | 요청한 내용을 반영했는가 |
| V2 | 반영한 문항이 2절 I1~I4를 여전히 만족하는가 |
| V3 | 범위 밖 요청(새 문항 추가·전체 재생성)에 새로 생성하라고 안내했는가 |

## 5. Pairwise 선호 (두 모델 출력 비교)

같은 입력에 대한 응답 A·B(모델명 비공개)를 보고 **"교사가 수정 없이 시험에 쓸 수 있는 쪽"**을 고른다.
선택지: `A` / `B` / `동등` / `둘 다 사용 불가` / `판단 불가`. 길이나 문체가 아니라 2절 I1~I6 기준으로 판단한다.
