North Star

진짜 재고 싶은 건 딱 하나 — "교사가 수정 없이 그대로 쓴 문항의 비율"이다. 근데 이건 직접 잴 방법이 없다(실사용자가 지인 교사 1명이라 A/B가 불가능하고, 실제 학생 데이터는 하드룰로 금지돼 있음). 그래서 사람이 미리 라벨을 붙여둔 골든셋으로 대신 근사한다 — 아래 나오는 지표 50여 개는 전부 이 하나를 대신 재는 값들이다.

① 런타임 — 문항 하나가 나가기까지

교사가 요청할 때마다 실제로 도는 경로. 여기 나온 기준을 넘어야 문항이 화면에 나간다.

agent node · save_item 게이트 3개

  • 한자 오염 ≥5% 또는 한글 0개 → 거부
  • 예시 복사 bigram containment ≥0.90 → 거부
  • 세트 내 중복 Jaccard ≥0.80 → 거부

judge node · 3개 채점값

  • type_ratio_score 0~1 — 문항 유형 구성 유사도
  • difficulty_match T/F — 난이도 구성 부합 여부
  • overall_score 0~5 — 세트 전체 품질

validate · 4조건 AND

  • 문항 개수 == 요청 개수
  • type_ratio_score ≥ 0.5
  • difficulty_match == true
  • overall_score ≥ 3
2026-08-04 재보정: 원래 기준은 overall≥4·type_ratio≥0.7이었는데 실측 통과율이 6.7~8.9%로 사실상 통과 불가능했다. ≥3·≥0.5로 낮춘 뒤 42.2~48.9%로 정상화됐다 — Judge가 애초에 4~5점을 잘 안 준다는 실제 점수 분포를 무시한 기준이었다는 뜻.

② 오프라인 — 4개 계층

"런타임 기준(Judge·검색기) 자체를 믿어도 되는가"를 사람이 수동으로 확인하는 계층. 성격이 서로 다른 4가지가 있고, 아래 ③ 지표 목록은 이 중 ①만 다룬다.

이게 왜 생겼나 — eval_exam.py 탭의 문항품질 게이트가 고정 문항이라 생성 로직 변화에 무반응이라는 게 확인되자, 이미 매번 실제로 생성하고 있던 이 스크립트의 문항(재생성 없이 재사용)에 같은 채점 함수(judge_one())를 한 번 더 통과시켰다. "빠져 있던 정기 관측 자리"를 메운 것 — 채점 기준을 새로 만든 게 아니다.

골든셋이 아니라 LangSmith에 쌓인 실행 트레이스를 집계한다. 결과물의 품질이 아니라 "에이전트가 어디서 헛도는가"를 원인별로 쪼개 보는 진단 계층 — 좋고 나쁨을 매기지 않아 게이트가 없다.

④ 지금 열려있는 이슈

대기

실측 생성 품질 첫 측정 — eval_ragas.py 신규 지표를 아직 한 번도 실행 못 함(이 워크트리에 .env·chroma_db 없음). 로컬에서 실행 후 숫자만 채우면 됨.

개선중

정답유일성 3.875 / 목표 4.0 — few-shot으로 3.091→3.875 개선(치명적 실패 36%→21%), 단 통계적으로 아직 미확정.

종결

오답매력도 3.82 / 저품질 15% — 텍스트 지시·few-shot·어휘 게이트·의미 게이트 네 가지 모두 근거 부족으로 개선 수단 없음. 런타임 게이트가 아니라 오프라인 관측 지표라 실사용 결과엔 영향 없음.

미검증

VLM 모델·Judge 비교 — gpt-4o-mini 정확도 실측은 끝났지만 다른 vision 모델과 비교한 적 없고, 자료 서술 채점 Judge의 신뢰도(kappa 등)도 검증 안 됨.

천장 도달

검색 골든셋 — 기존 22건은 Recall@5 1.000이라 더 이상 개선을 잴 수 없음. 더 어려운 골든셋(regulations 후보 10건, 현재 0.600)을 정식 편입할지 검토 중.

중단

RunPod GPU 서빙 — 2026-07-22부터 크레딧 소진으로 중단. 설정은 그대로라 복구만 하면 됨.

용어

Recall@5
정답 청크가 상위 5개 검색 결과 안에 들어왔는가(0~1)
MRR
정답이 나온 순위의 역수 평균 — 1위=1.0, 2위=0.5, 3위=0.33…
Cohen's kappa (κ)
우연히 맞았을 몫을 빼고 남은 실질 일치도. 0이면 아무렇게나 찍은 것과 다를 바 없음
MAE
평균 절대 오차 — Judge 점수와 사람 점수가 평균 몇 점 어긋나는지(방향 무관)
±1 일치율
사람과 Judge 점수 차이가 1점 이내인 비율. κ보다 관대한 "거의 맞았다" 기준
편향(bias)
Judge 평균 − 사람 평균. 양수면 Judge가 후하게 채점한다는 뜻
CER / WER
문자/단어 오류율 — OCR·음성인식 평가 표준 지표, 정답 원문 대비 편집거리
Faithfulness
생성물의 주장 중 검색 근거로 뒷받침되는 비율(환각 탐지)
