# 분필(Bunpil) 프론트엔드

Next.js UI. 실행 방법·필수 환경변수(`BUNPIL_API_KEY`, `BACKEND_URL`)는 이 저장소 루트의
[README.md](../README.md) "빠른 시작 (로컬)" 절을 참고 — `npm run dev`만으로는 백엔드 인증이
안 돼 정상 동작하지 않는다.

`create-next-app` 기본 템플릿(App Router, `next/font`)을 그대로 씀. Next.js 자체 사용법은
[nextjs.org/docs](https://nextjs.org/docs) 참고.
